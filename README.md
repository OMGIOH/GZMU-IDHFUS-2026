# 首届国际大学生数字人文节优秀作品展示通知

> 【本通知无须回复"收到"，请拟参加展示的同学直接在群内接龙确认。】

各位同学好！

祝贺大家从两百余份参赛作品中脱颖而出，入围首届国际大学生数字人文节优秀作品评审环节！为充分展示入选作品的创新成果与独特风采，让参会嘉宾和在校师生深入了解作品内容，主办方将统一设置作品展区，并为各项目预留展板。具体安排如下：

## 一、展出时间及地点

- **9月18日全天**：中国人民大学逸夫会堂前广场（开幕式会场）
- **9月20日上午**：中国人民大学立德楼（作品评选分会场）

## 二、参加方式

根据学校关于宣传品审批的有关要求，请于 **9月13日（周日）17:00 前**，将海报电子版发送至 idhfus@ruc.edu.cn

- 邮件及附件标题：`优秀入围作品-学校-主申请人姓名`

## 三、海报要求

1. 尺寸为 **80厘米 × 120厘米（竖版）**；
2. 须包含活动统一表头（见群内附件）；
3. 海报由各项目团队自行设计制作，建议采用自带背胶的材质，以便现场张贴。

## 四、张贴安排

**9月17日 14:00 至 20:00**，请各项目团队前往中国人民大学立德楼 B1 数字人文研究院张贴海报。
